# style_pack

One-time setup assets. None of these are generated — you supply them.

## Required before Stage 0

| File | What | Notes |
|------|------|-------|
| `voice_ref.wav` | 12-15 sec clean voice sample | Quiet room, no music, AirPods mic ok. Gitignored. |
| `fonts/` | 3 font files | Inter (body), heavy display, mono |
| `colors.json` | Brand palette | Edit the placeholder |
| `music/intro.wav` | Intro music bed | ~30s, fades in/out |
| `music/build.wav` | Build/tension bed | |
| `music/tense.wav` | Tense/drama bed | |
| `music/chill.wav` | Calm/explanatory bed | |
| `music/outro.wav` | Outro bed | ~30s |
| `sfx/` | 15 SFX files | whooshes, impacts, ticks, transitions |

All music/SFX must be royalty-free with no attribution required, or attribution tracked in `projects/*/credits.json`.
